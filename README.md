This project demonstrates SQL skills using a Sales Management Database containing product details and purchase transactions.
It includes database creation, table design, data insertion, and SQL queries for aggregation, grouping, sorting, and business insights.

Dataset Summary
Products:

Includes 25 products such as Laptop, Smartphone, Tablet, Speaker, Accessories, etc.
Each product has:

Price

Stock quantity

Purchased quantity

Date received

Purchases:

The dataset includes 25 transactions, one per customer, covering:

Customer name

Product purchased

Purchase date

Total purchase amount

Skills Demonstrated

SQL database design

Primary and foreign key relationships

Aggregate functions (AVG, SUM, MAX, MIN)

GROUP BY and HAVING

Sorting with ORDER BY

Basic data analysis on sales and product performance
